<h1 align="center">💄 Makeup Appointment Planner</h1>
<p align="center">A simple and efficient appointment scheduling system for makeup artists and clients.</p>

---

## Project Overview
This web application allows clients to book appointments with a makeup artist while preventing double bookings.
The system also includes an admin panel for managing appointments, viewing schedules, and handling client information.

This project is created as a final requirement for ITEP 308 – System Integration & Architecture.
